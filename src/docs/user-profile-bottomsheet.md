■ 프로필 바텀시트 진입
▣ 노출 조건
채팅 메시지의 프로필 이미지 or 닉네임 영역 탭 시 노출, 비회원 진입시 노출되지 않음
▣ 진입 가능 화면
채팅 탭 진입 시 전체 채팅 화면
몰입형 투표 바텀시트형 채팅 화면
일반형 투표 바텀시트형 채팅 화면
위 3개 화면 모두 동일한 유저 프로필 바텀시트로 진입
▣ 인터랙션
닉네임 탭 → 해당 유저의 프로필 바텀시트 노출

■ 참여투표 영역
▣ 상단 — 참여투표 개수
참여투표 총 개수 표시 (예: "참여투표 24")
▣ 카드 구성 요소
투표 상태 라벨 — "진행중" / "종료" (텍스트 + 색상 구분)
투표 제목 (1줄 말줄임 처리)
본인이 선택한 선택지 텍스트 (체크 아이콘 + 1줄 말줄임 처리)
우측 화살표(>) 아이콘
 노출 조건
참여한 투표 리스트 최대 3개까지 노출 (최신 활동순)
최신순 기준: 투표 생성 시각이 아닌, 사용자가 해당 투표에 참여하거나 활동한 시각 기준
3개 초과 시 추가 항목은 노출하지 않음 (더보기 없음)
▣ 예외 케이스
참여한 투표가 1~2개인 경우 → 있는 개수만큼만 노출 (빈 슬롯 없음)

---

■ 투표 리스트 카드 탭 — 화면 랜딩
투표 상태(진행중/종료), 본인의 참여 여부, 프로필 진입 전 사용자가 머무르던 투표 화면 타입에 따라 랜딩 화면이 분기됨.
▣ 인터랙션 / 화면 랜딩
진행중 + 일반형 투표 → [일반형 투표_회원]으로 이동
진행중 + 몰입형 투표 → [몰입형 투표_회원]으로 이동
종료 + 본인이 참여한 투표 → [투표결과_회원_참여O]로 이동
종료 + 본인이 참여하지 않은 투표 → [투표결과_회원_참여X]로 이동
▣ 예외 케이스
삭제된 투표 탭 시 → "삭제된 투표입니다" Error 토스트 메세지 노출, 랜딩 없음

투표 제목, 선택지 텍스트는 모두 1줄까지만 노출
컨테이너 영역을 초과할 경우 말줄임(...) 처리

참여한 투표 노출 개수
참여한 투표는 최대 3개까지 노출
3개 초과 시 추가 항목은 노출하지 않음 (더보기 없음)

프로필 바텀시트 높이
다른 유저 프로필 조회용 바텀시트는 고정 높이(500px)로 사용
콘텐츠 양에 따라 바텀시트가 확장되지 않음

최근 활동 정렬 기준
최근 활동 리스트는 항상 최신순으로 노출
최신순 기준: 투표 생성 시각이 아닌, 사용자가 해당 투표에 참여하거나 활동한 시각 기준

바텀시트 Dim 처리
바텀시트 오픈 시 배경에 Dim Layer 적용
색상: #000000, 투명도: 40%

다크 모드 대응
다크 모드에서는 바텀시트 외곽선(Stroke) 추가

투표 리스트 터치영역

# 회원가입 요구사항 정의서

회원가입은 **약관동의 → 성별/출생년도 입력 → 프로필이미지 선택/닉네임 입력 → 회원가입 성공**까지 총 네 가지 퍼널로 구성됩니다.

---

## 1. 약관 동의
회원가입을 위한 필수 및 선택 약관에 대한 동의 단계입니다.

### ▣ 항목 구성
* **만 19세 이상** (필수)
* **개인정보 수집** (필수)
* **서비스 이용약관** (필수)
* **푸시 알림 동의** (선택)

### ▣ 전체 동의 체크박스
하위 모든 항목(필수 + 선택)을 한 번에 동의 처리하는 기능입니다.
* **인터랙션**:
    * 체크 시: 하위 항목 전체 선택
    * 해제 시: 하위 항목 전체 해제
    * 하위 항목 개별 해제 시: 전체 동의 체크 자동 해제
    * 하위 항목 전체 체크 시: 전체 동의 자동 체크

---

## 2. 성별/출생년도 입력
사용자의 기본 인적 사항을 입력받는 단계입니다. 두 항목을 모두 올바르게 입력해야 다음 단계로 이동 가능합니다.

### ▣ 성별 입력
* **선택 옵션**: 남성 / 여성 (두 가지 중 하나 선택)
* **인터랙션**: 
    * 한쪽이 선택된 상태에서 다른 쪽을 선택하면 변경됨
    * 선택된 항목을 다시 클릭해도 해제되지 않음 (토글 불가)

### ▣ 출생 연도 입력
4자리 출생 연도를 입력하는 필수 항목입니다.
* **구성 요소**:
    * 레이블: "출생 연도"
    * 텍스트 필드: 숫자 전용 키패드 호출
* **입력 공통 사항**:
    * 최대 4자리 제한 (4자리 입력 시 타이핑 불가)
    * 숫자만 입력 가능 (문자 입력 차단)
* **인터랙션**:
    * 텍스트 필드 탭: 숫자 전용 키패드 호출
    * 유효한 4자리 연도 입력 완료: 다음 버튼 활성화
* **예외 케이스 및 에러 메시지**:
    * **상식적으로 불가능한 연도 입력 시** (예: 1900년 이전, 가입 불가 연도 이후)
        * 다음 버튼 비활성 유지
        * 에러 메시지: "올바른 출생 연도를 입력해 주세요."
    * **만 19세 미만 연도 입력 시** (2026년 기준, 2008년생부터 가입 불가)
        * 다음 버튼 비활성 유지
        * 에러 메시지: "만 19세 미만은 가입할 수 없어요."
        * 에러 메시지 노출 위치: 출생 연도 필드 하단
    * *※ 만 19세 기준 연도는 매년 자동 갱신됨 (현재 기준 연도: 2026년)*

---

## 3. 프로필 이미지 선택 및 닉네임 입력
서비스 내에서 사용할 프로필과 닉네임을 설정하는 단계입니다.

### ▣ 프로필 이미지 선택
* 사용자가 직접 업로드하지 않으며, **네 가지 색상의 기본 프로필** 중 하나를 선택합니다.

### ▣ 닉네임 입력
최대 10자의 닉네임을 설정합니다.
* **기본값**: 랜덤 닉네임 자동 배정 (사용자 수정 가능)
* **구성 요소**:
    * 텍스트 필드
    * 인풋 내 우측 글자수 카운터: (현재 입력수/10)
    * 필드 하단 Help Text: "한글/영문(대소문자)/숫자/특수기호(_)로 설정할 수 있어요"
* **입력 공통 사항**:
    * 최대 10자 입력 가능 (초과 입력 불가)
* **인터랙션 및 상태별 처리**:
    * 텍스트 필드 탭: Help Text 노출 + 키패드 호출 + 입력폼 Stroke 강조
    * 자동 배정된 닉네임 미변경 시: 저장 버튼 비활성화 (대신 [나중에 할게요]로 건너뛰기 가능)
    * 유효한 닉네임 입력 완료 시: 저장 버튼 활성화
    * 포커스 해제(빈 칸 클릭) 시: Stroke 색상 Default로 변경
    * 입력 글자 전체 삭제 시: Placeholder "닉네임을 입력해 주세요." 노출
* **예외 케이스 및 에러 메시지** (필드 하단 Help Text 대체 노출):
    * **언더바(_) 조건 위반**: "언더바(_)는 중간에 1개만 사용할 수 있어요"
    * **글자수 미달(2자 미만)**: "2자 이상 입력해주세요"
    * **금칙어 포함**: "이미 사용 중인 닉네임이에요"
    * **미입력(0자) 상태**: Placeholder 노출 및 저장 버튼 비활성
    * **사용 불가 단어 포함**: "사용할 수 없는 단어가 포함되어 있어요"

---

## 4. 가입 완료
* 회원가입 완료를 알리는 정보성 페이지입니다.

---

## ▣ 공통 시스템 요구사항
* **다음 버튼**: 페이지 하단에 항상 노출되며, 각 퍼널의 유효성 검사가 통과될 때만 활성화됩니다. 각 퍼널마다 다음, 다음, 저장, 확인으로 바뀐다.
* **컴포넌트 구조**: 인풋(Input) 필드는 재사용성을 위해 별도의 공통 컴포넌트로 분리하여 구현해야 합니다.

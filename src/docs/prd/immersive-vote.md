# 1. 투표 상세 - 회원 (VOTE)
> 회원 투표 / 투표 완료 상태 포함

## 화면 설명
투표 본문(텍스트 + 이미지) 기반의 몰입형 투표 화면 (다크모드 적용)
질문, 설명, 이미지가 함께 노출됨
로그인 상태에서 투표 상세 정보를 확인하고 참여 가능
투표 선택, 이모지 반응, 채팅, 공유 기능 포함

## 1-1 투표 남은 시간
남은 시간 실시간 갱신
타이머 종료 시 :  1-6 투표종료 푸시 알림

## 1-2 본문 인터랙션
“전체 보기” 클릭 → 본문 펼치기
“접기” 클릭 → 본문 축소

## 1-3 투표 선택 영역

사용자 참여에 따라 선택 항목의 비율이 위아래로 변동하며, 결과가 실시간으로 뒤바뀌는 흐름을 제공 

정책
- 투표
  - 투표는 생성 시점 기준 12시간 또는 24시간 동안 참여 가능
  - 투표 횟수 제한 없음
  - 동일 투표 내 선택 변경 및 취소 가능
  - 몰입형 투표 인터랙션 디스크립션
    - A/B 선택지 중 하나 선택 시 즉시 투표 결과 상태로 전환
    - 결과 노출 시 각 선택지의 득표율에 맞게 filled bar가 하단 → 상단으로 애니메이션
    - 애니메이션: smart animate, ease-out, 600ms
    - 다른 유저의 투표로 득표율 변경 시, filled bar 높이 실시간 업데이트 (애니메이션 동일 적용)
    - 사용자가 선택한 선택지를 다시 탭하면 투표 취소 → 결과 재계산 후 bar 업데이트
- 이모지
  - 이모지는 1개만 선택 가능
  - 동일 이모지 재클릭 시 선택 취소
  - 다른 이모지 선택 시 기존 선택 자동 해제
  - 선택한 이모지는 프라이머리 컬러로 강조 표시
  - 이모지 선택 시 플로팅 애니메이션 노출
  - 플로팅 이모지 인터랙션 디스크립션
    - 이모지 아이콘 탭 시 이모지 목록 노출, 재탭 시 목록 닫힘
    - 이모지 선택 시
    - 해당 이모지 카운트 +1
    - 선택한 이모지 카운트 프라이머리 컬러 강조
    - 동시에 선택한 이모지가 아이콘 바로 위에서 생성 → 상단 이동 → fade out 애니메이션
    - 이모지는 단일 선택만 가능
    - 동일 이모지 재탭 시 선택 취소 (카운트 -1, 강조 해제)
    - 다른 이모지 선택 시
    - 기존 선택 이모지 취소 (카운트 -1)
    - 새 이모지 선택 (카운트 +1)
    - 플로팅 애니메이션은 새 이모지 기준으로 실행

▷ 투표 전
 A / B 선택지 노출
▷ 투표 후
 선택 시:
 선택 항목 강조
 실시간 결과 영역 노출
 퍼센트 반영
▷ 재선택
 다른 선택지 클릭 → 선택 변경
 동일 선택지 재클릭 → 선택 취소 ( “다시 투표하기” 버튼 없음 )
▷ 투표 선택영역 인터랙션
 사용자가 투표에 참여하면, 다른 이용자들의 참여에 따라 선택 항목의 비율이 위아래로 변동하며 결과가 실시간으로 변화하는 것을 확인할 수 있음

## 1-4 다음 투표 이동
위로 스와이프 시 다음 투표로 이동 : 랜덤으로 다음 투표 이동 ( 무한 순환)

## 1-5 Live 실시간 참여 토스트
문구: “현재 n명이 참여중이에요!” (n: 참여자 수)
노출 조건:
 화면을 보고 있는 실시간 사용자 수가 10명 이상일 경우
 조건 충족 시 즉시 5초간 노출
 이후 사용자 수가 10명 이상으로 유지될 경우, 60초 간격으로 반복 노출

# 2.  이모지 반응 영역
설명
투표에 대한 감정 반응을 표현하는 인터랙션 영역
이모지 선택 시 개별 반응 수 + 전체 반응 흐름(플로팅)이 함께 반영됨
몰입형 경험을 위해 이모지 UI는 화면 우측에 상시 노출됨

UI 구성
## 2-1 기본 상태
 화면 우측에 플로팅 버튼 형태로 노출
 대표 이모지 + 전체 반응 수 표시
 예: 😊 131 (전체 이모지 합계)
## 2-2 이모지  UI
 버튼 클릭 시 이모지 리스트 노출 (말풍선 형태)
 2-1 상태에서 1회 클릭 → 2-2  상태로 확장
 2-2 상태에서 다시 클릭 → 이모지 바 접힘 (2-1 상태)

이모지 4종 구성
 😊 공감 
 😢 슬픔 
 😡 분노 
 😍 호감 
 각 이모지별 개별 카운트 표시
 예: 😊 21 / 😢 3 / 😡 8 / 😍 36

인터랙션
이모지 선택
이모지 클릭 시:
 해당 이모지 카운트 증가
 전체 반응 수 증가
 선택한 이모지 프라이머리 컬러로 강조 표시
이모지 변경 / 취소
 동일 이모지 재클릭 → 선택 취소
 다른 이모지 클릭 → 기존 선택 자동 해제 후 변경
항상 1개의 이모지만 선택 가능

## 2-3 플로팅 이모지
이모지 선택 시:
 선택한 이모지가 화면 하단 → 상단으로 이동하는 플로팅 애니메이션 실행
 여러 개가 랜덤 위치에서 자연스럽게 떠오름(3초 후 자동 사라짐)
표시 로직
2-1 전체 반응 수
 모든 이모지 카운트의 합계
2-2 개별 반응 수
 각 이모지별 선택 수

예외케이스

 카운트 반영되지 않음
  Error 토스트 문구: “이모지 반응에 실패했어요” (2초 노출)

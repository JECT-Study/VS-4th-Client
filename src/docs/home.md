■ 핫토픽 TOP 5 
실시간 인기 투표 상위 5개를 노출하는 영역. 1~3위는 카러셀, 4~5위는 리스트형으로 구분 노출.

▣ 노출 조건
상시 노출 (투표가 존재하지 않는 경우 없음)
최대 5개 고정 노출, 6위 이하 미노출
진행중 투표가 5개 미만인 경우 → 있는 개수만큼만 노출 (빈 슬롯 없음)
진행중 투표 3개 미만 → 카러셀 슬롯 해당 개수만큼만 노출
진행중 투표 4개 → 카러셀 3개 + 리스트 1개 노출

▣구성 요소 : 순위 뱃지 / 썸네일 / 제목 / 내용 / 투표 종료 시간 / 참여자 수 
순위 뱃지- 1위~3위는 썸네일 왼쪽 상단에 표시- 4위~5위는 기존과 동일하게 리스트 왼쪽에 표시
제목/ 내용- 영역 초과 시 말줄임 처리 (줄내림X)

■ 상단 카러셀 (1~3위)
▣ 카러셀 동작 방식
수동 스와이프

▣ 인터랙션
카드 탭 시 → 일반형 투표 화면(홈_메인_투표상세페이지_투표진행중)으로 이동

■ 하단 리스트 (4~5위)
▣ 인터랙션
